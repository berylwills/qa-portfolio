# Feature map: [sauce_demo](https://www.saucedemo.com/)
- Browser used: Chrome Browser
- Date: 29th Oct, 2026
- User: Standard_user

## Login 
- Input username and password  
- Log in 

## Products Page
- Sort products by name (A-Z / Z-A) or by price (low-high / high-low).
- View product details
- Add four items to cart
- Verify social Media Hyperlinks

## Cart Page
- Remove an item from cart
- Click on "continue shopping"
- Go back to cart
- check out

## Checkout Page
- Input user information
- View checkout overview
- Finish checkout 
- Download the order in pdf format
- Logout
